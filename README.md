## סצנה: Part2c (תרגיל 2ג)

בסצנה זו ממומש תהליך אינטראקציה בין השחקן לבין אובייקט בסביבה (תיבה).

מה קורה בסצנה:
- השחקן נע בסביבה ומתקרב לתיבה.
- כאשר השחקן נמצא בטווח אינטראקציה ולוחץ על מקש E במקלדת, התיבה “נפתחת”.
- פתיחת התיבה מיוצגת בצורה ויזואלית באמצעות שינוי צבע של התיבה, כך שהמשתמש מקבל פידבק מיידי שהפעולה הצליחה.
.

## סצנה: Part3b (תרגיל 3ב)

בסצנה זו ממומש אויב שיורה לעבר השחקן באמצעות Raycast (לייזר) ובדיקת פגיעה.

מה קורה בסצנה:
- האויב יורה לייזר בכיוון השחקן באמצעות Raycast.
- ללייזר יש טווח של בערך 100 יחידות.
- ירידת חיים לשחקן מתרחשת רק אם הלייזר פוגע בפועל בשחקן.
- בכל פגיעה מודפס ל-Console (Log) מצב החיים המעודכן.
